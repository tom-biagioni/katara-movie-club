# Katara's Movie Club 🎬

A single-page movie club site — 147 movies and 6 TV shows hand-picked by Dad,
with posters, mood filters, search, watch-tracking, and a Surprise Me picker.

Built from a humble list in `Mind Map 4.md`. Served with love (and GitHub Pages)
from `index.html`. Poster thumbnails belong to their respective studios.
